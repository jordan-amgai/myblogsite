# Favorite Games Blog

A simple static blog where I write about my all-time favorite video games.

## Pages

- **Home** (`index.html`): Blog posts and latest updates
- **About** (`about.html`): About me and why I love these games
- **Contact** (`contact.html`): Ways to get in touch

## Project Structure

```
├── css/            # Stylesheets
├── js/             # JavaScript files
├── about.html
├── contact.html
├── index.html
└── stylels         # Extra styles
```

## How to Run

1. Clone the repo:
   ```
   git clone https://github.com/jordan-amgai/REPO-NAME.git
   ```
2. Open `index.html` in your browser.

No build tools or installs needed.
